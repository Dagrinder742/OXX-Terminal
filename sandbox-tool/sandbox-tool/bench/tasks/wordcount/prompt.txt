Create wc.py with two functions.

count_words(text): return a dict mapping each word to how many times it appears. Make everything lowercase. Words are separated by whitespace. Remove these punctuation characters from both ends of each word: . , ! ? ; : " ' ( ). Ignore items that are empty after removing them. count_words("") returns {}.

top_words(text, n): return a list of (word, count) tuples for the n most frequent words, highest count first. If counts tie, put those words in alphabetical order. If there are fewer than n different words, return all of them.

Do not print anything when the file is imported. At the bottom of the file: if __name__ == "__main__": print(top_words("the cat and the hat and the bat", 2))
