The Unified System Blueprint: Project One
Our target system is an asynchronous cryptocurrency market data engine structured into three interdependent layers:
 * Layer 1 (Resilience): An asynchronous WebSocket connection loop equipped with exponential backoff, jitter, and automatic reconnection handlers to survive network drops without memory leaks.
 * Layer 2 (State Synchronization): An in-memory local order book class that processes initial snapshots and incremental delta updates (l2update), enforces strict price sorting (bids descending, asks ascending), and performs sequence-gap validation.
 * Layer 3 (Optimization & Telemetry): A resource-optimized controller that decouples the high-frequency ingestion loop from background logging and telemetry layers using asyncio.Lock to ensure zero lag.
